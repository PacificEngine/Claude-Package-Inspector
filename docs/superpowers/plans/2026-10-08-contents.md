# Contents Implementation Plan (Phase 2)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Give every package real contents (weighable, throwable, sometimes leaking) so wrong weight is fixed by throwing away stowaways, soggy cardboard may need a leaking item sealed first, and a missing contents label is reprinted to match what is inside.

**Architecture:** Items live on the package (`Package.contents`); what the player has done to them lives in the handling (`discarded`, `sealed`, `labelItems`). Pure helpers in `src/game/contents.ts` compute what is left, the current weight and whether the label matches; rules, repairs and actions use them. The UI draws the remaining items and renders a Contents list from the same helpers.

**Tech Stack:** TypeScript (strict), Vite, Vitest, yarn. No new dependencies.

**Spec:** `docs/superpowers/specs/2026-10-08-contents-design.md`

## Global Constraints

- `yarn` only. TDD: failing test first, watch it fail, minimal code.
- Branch `feature/contents` (already created from `feature/faces-and-shapes`). Never commit to `main`.
- Commit messages explain *why*. NO `Co-Authored-By`, no "Generated with", no signature or trailer. Never stage `.superpowers/`.
- No new dependencies. `src/game/` must not import `src/ui/` or `src/audio/` or touch the DOM. UI text via DOM APIs only, never `innerHTML`.
- Snyk is not required; do not run it.
- Every task ends with `yarn test && yarn tsc --noEmit && yarn build` green.
- Weights are in kg rounded to one decimal; a package's weight matches its declared weight when they differ by less than 0.05.
- Items are plain nouns ("teapot"), so sentences read "The teapot weighs 0.6 kg."

```ts
const round1 = (n: number): number => Math.round(n * 10) / 10;

// One to three distinct catalog items (one or two for cylinders), each a little heavier or lighter.
function legitItems(rng: Rng, kind: PackageKind): Item[] {
  const pool = [...CATALOG[kind]];
  const cylinder = kind === 'can' || kind === 'jar' || kind === 'tube';
  const count = 1 + rng.int(cylinder ? 2 : 3);
  const items: Item[] = [];
  for (let i = 0; i < count; i++) {
    const [pick] = pool.splice(rng.int(pool.length), 1);
    items.push({
      id: i + 1,
      name: pick.name,
      art: pick.art,
      color: pick.color,
      weightKg: round1(pick.baseKg + rng.int(3) / 10),
    });
  }
  return items;
}

// A wrong weight is one or two stowaways that together weigh the difference.
function stowaways(rng: Rng, firstId: number): Item[] {
  const excess = round1(0.6 + rng.int(7) / 10);
  const kinds = [...STOWAWAYS];
  const take = (weightKg: number, id: number): Item => {
    const [pick] = kinds.splice(rng.int(kinds.length), 1);
    return { id, name: pick.name, art: pick.art, color: pick.color, weightKg, extra: true };
  };
  if (rng.chance(0.5)) {
    const first = round1(Math.floor((excess * 10) / 2) / 10);
    return [take(first, firstId), take(round1(excess - first), firstId + 1)];
  }
  return [take(excess, firstId)];
}
```

```ts
export interface ItemSlot {
  cx: number;
  scale: number;
  rect: Rect;
}

// Items stand side by side on the floor of the cutaway, smaller as there are more of them.
export function itemSlots(count: number, width: number, height: number): ItemSlot[] {
  if (count === 0) return [];
  const { wall, floorY, cx } = insideLayout(width, height);
  const scale = count <= 2 ? 1.5 : count <= 4 ? 1.1 : 0.85;
  const gap = Math.min(80 * scale, (wall.w - 16) / count);
  const left = cx - (gap * (count - 1)) / 2;
  const top = Math.max(wall.y + 24, floorY - 70 * scale);
  return Array.from({ length: count }, (_, i) => {
    const x = left + i * gap;
    return {
      cx: x,
      scale,
      rect: { x: x - gap / 2, y: top, w: gap, h: floorY + 12 - top },
    };
  });
}
```
